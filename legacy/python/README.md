# Legacy Python Prototype

Bu klasör Pocket Music'in ilk Python prototipini içerir (menü çubuğu + Spotlight).

**Aktif geliştirme:** `../PocketMusicSwift/` (native Swift uygulaması)

## Kurulum (eski)

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
brew install yt-dlp mpv
```

## Not

Yeni kullanıcılar için `PocketMusicSwift/install.sh` kullanın.
